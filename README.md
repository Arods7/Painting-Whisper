# Painting Whisper 🎨

هر روز، دقیقاً یک نقاشی — برای همه‌ی دنیا یکی.

**Painting Whisper** سایتی ساده و بدون بک‌اند که **هر روز یک شاهکار رندوم** از مجموعه‌ی متن‌باز موزه‌ی مت (Metropolitan Museum of Art) را نمایش می‌دهد: عنوان، هنرمند، سال، تکنیک و تصویر باکیفیت.

## ✨ ویژگی‌ها
- **انتخاب روزانه و قطعی** — الگوریتم بر اساس تاریخ روز یک نقاشی برمی‌دارد؛ پس همه‌ی بازدیدکننده‌ها در یک روز، همان یک اثر را می‌بینند. فردا، خودکار اثر بعدی!
- **۷۵ شاهکار مالکیت عمومی** — کاراواجو، ورمیر، رامبراند، ال گرکو، بوتیکلی، کورتبه، رنوآر و…
- **تاریخ شمسی** — با `Intl.DateTimeFormat("fa-IR")`
- **بدون بک‌اند، بدون کتابخانه** — HTML + CSS + JS خالص
- **تصاویر لوکال** — همه‌ی تصاویر داخل پروژه‌اند؛ نیازی به API خارجی نیست
- **دکمه‌ی اشتراک‌گذاری** — Web Share API با fallback به کپی لینک
- **ریسپانسیو کامل** — از ۳۹۰ پیکسل تا دسکتاپ

## 🚀 اجرا
فقط فایل‌ها را روی هر وب‌سرور ساده بگذارید:

```bash
python -m http.server 8000
# http://localhost:8000
```

## 🌍 دیپلوی روی GitHub Pages
1. این ریپو را بسازید و فایل‌ها را push کنید
2. `Settings → Pages → Branch: main / root`
3. تمام — سایت روی `https://USERNAME.github.io/REPO/` منتشر می‌شود
